# 切り出し版の範囲(scope)

授業デザインナビ(設計書 2026-11-04 版)のうち、このリポジトリで作る範囲です。節番号は設計書のものです。

## 作るもの(必須)

- 授業資産のテキスト貼り付け。単元の入力は任意(3.2)
- 学校レベル3種(進学校 / 中堅校 / 基礎定着重視校)と、3観点ごとの1段調整。上端・下端は動かさない(3.2・11.2)
- 授業時間(既定50分)、活動の進め方(ペア・練り上げ・1回の上限、その他の自由入力)(3.2)
- 教室環境プロファイルの最小版: 授業の形、用紙と向き、氏名欄、解答欄の高さ(4・9.2)。授業の形と提示設備は授業ごとに持ち、プロファイルは初期値
- 提示設備の入力: 「黒板・ホワイトボードのみ」「投影も使う」の2択(4)
- 授業の形「板書・ノート中心」と板書計画(3.2・3.3)
- 設計の出力: 活動の一覧、仕分けと理由、改善提案(3観点・重点観点)、解答欄の区分、優先度、要確認一覧、読み取った単元・ねらい(推定)(3.3)
- 仕分けの判断順序、時間の見積り、出力前の自動チェック(2・5・6.1)
- 確定データ(スナップショット)(3.1)
- 検算と「要確認」(3.7)
- 確認画面は、必ず見る点(未確認の要確認・時間超過)を最上段に出し、改善提案・解答欄の区分・優先度は初期は折りたたむ(3.14)
- 制作: 生徒用プリント(用紙A4/B4/A3、向き、氏名欄、通し番号、優先度の印、聞き手メモ欄、ふり返り欄)と、教師用の当日の1枚(簡易。旧: 時間配分表)(3.3・3.4・3.9・6.2)。板書・ノート中心のときは、板書計画が当日の1枚を兼ねる(別の表は出さない)。
- 当日の1枚(簡易)の中身(プリント中心のとき): 時刻・活動と手法・やること(定型文)・優先度の印・注意・合計と余り・紙の記録欄(3.3・3.4・3.9・3.12・6.2)
- 「AIの下書きです」の表示と、配布前チェック(3.3)
- 利用条件ページ(検算は保証ではない、など)(9.5)

## 余力があれば作るもの

- ペア・班の活動の進め方の表(3.3)
- 確定データの書き出し・読み込み

## 作らないもの(意図的に外した)

- 画像・PDFの取り込み(OCR)、単元・着眼点ナビとの統合・検索
- 教科書の表示モードと、教材の種別
- 解説つき全文解答、要点スライド、教師用の指導案本体(発問・想定反応)、評価規準・評価教材(指導案には、当日の1枚の「先生の一言」「ここだけ注意」を含む)
- 年間計画・進度(公開後の任意タスク)、実施ログ(最小の記録の入力・保存を含む。紙の記録欄だけ、当日の1枚(簡易)に印刷する)、実績での補正
- 当日モード(端末で当日の1枚を進める画面。3.15で見送り)
- 生徒の入力画面、決済、共有、学校導入の説明資料
- 提示設備の細かい選択(2択より細かい分け方。その他の自由入力、実物投影機、班で1台など)
- 生徒の個人情報・成績・レポートを扱う機能、AIによる評定・合否の自動決定
- 入口(困りごとの選択)と、目的のセット・「いつものセット」: 公開後に足す(3.4・3.11)
- 部分設計(授業の一部の活動・問題だけを設計する): 公開後に足す(3.13)
- 付箋式の簡易版(問題番号ごとの変更メモ): 公開後に足す(3.15)

## 範囲を決める原則

- 1本の流れ(入力 → 仕分け → 確認・修正 → 確定 → 印刷)を、最後まで動かすことを優先する。
- 判断ロジックと時間の計算は、サーバー側のコードで行う。AIは特徴の抽出と、文章の生成だけを担当する。
- 遅れたときに削る順: 余力 → 印刷の見た目(当日の1枚(簡易)の「やること」の列と紙の記録欄を含む) → AIの理由文と単元の推定 → 検算の例外処理。
- 削らないもの: 段階1〜4(土台・DB・画面・ルールエンジン)、テスト、CI、保存期限と削除、利用条件ページ。

## 公開しないもの

設計書の全文、料金、事業計画、製品版の差別化部分は、このリポジトリに置きません。
